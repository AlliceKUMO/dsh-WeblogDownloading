# 微博收藏下载器

下载微博收藏中的**正文文字**与**图片原图**，按 `用户名-微博时间` 分文件夹保存。

## 🚀 获取成品（不想碰代码的话）

仓库 `release/` 目录里有打包好的成品 zip：
**[`release/微博收藏下载器-v1.2.zip`](release/微博收藏下载器-v1.2.zip)** —— 解压后双击里面的 `微博收藏下载器.exe` 即可使用（无需安装 Python）。

> 从 GitHub 页面下载：点进 `release` 文件夹 → 点击 `微博收藏下载器-v1.2.zip` → Download。
> 程序为文件夹版（exe 与旁边依赖文件需整体保留）；下载目录默认在「我的文档\微博收藏下载」，更新程序不影响已下载数据。

### 更新记录

- **v1.1**：默认下载目录迁至「我的文档」、错误日志落盘、修复失败路径静默崩溃、支持自定义列表接口

## 图形界面（推荐）

解压 `dist\微博收藏下载器.zip`，进入 `微博收藏下载器` 文件夹，**双击里面的 `微博收藏下载器.exe`** 即可使用（无需安装 Python / 命令行）。包含：

- **批量模式**：全自动下载全部收藏；开始/暂停/继续/停止；可选「下载成功后自动取消收藏」
- **手动模式**：逐条浏览（正文 + 图片缩略图预览），可 **下载此条** / **下载并取消收藏** / **仅取消收藏** / **跳过**
- 实时日志、已下载清单表格、Cookie 粘贴保存、下载目录选择、打开下载目录

> **重要**：程序是「文件夹版」——`exe` 和旁边的依赖文件（dll/pyd 等）必须**整体一起拷贝、放在同一文件夹**，不能只拷 exe 单独拿走。这是为了避开单文件版（onefile）启动时解压被安全软件拦截导致的 "fatal error detected" 弹窗。若安全软件提示拦截，请把整个文件夹加入信任/白名单。

使用流程：

1. 打开程序 → 粘贴 Cookie（F12 → 网络 → 刷新收藏页 → 点开 `weibo.com/ajax/collection` 请求 → 复制请求头中的 Cookie 整段）→ 点「保存 Cookie」→ 点「测试连接」确认可用
2. 下载目录默认在 **「我的文档\微博收藏下载」**（与程序分离，更新程序不会影响数据）；也可以在界面上点「浏览」自由选择
3. 「批量模式」点「开始下载」，或切到「手动模式」逐条挑选
4. 取消收藏操作有二次确认弹窗；下载失败不会触发取消

> **升级说明**：新版程序请解压到**新文件夹**使用（或覆盖旧文件夹——更新流程会自动备份 `config.json`（Cookie 配置）与下载数据，但建议先手动确认）。下载的数据都在「我的文档\微博收藏下载」，不受程序更新影响。

> **接口改版怎么办**：收藏页面的网址是 `https://weibo.com/u/page/fav/<uid>`，但脚本用的是页面背后加载数据的接口（默认 `weibo.com/ajax/collection/list`）。若「测试连接」失败，按 F12 → 网络 → 刷新收藏页 → 在过滤框输入 `fav` 或 `collection`，看实际发出的**接口请求完整 URL**，填入界面「列表接口」输入框后点「保存 Cookie」再测试。测试连接失败时，界面/日志会显示接口返回内容，方便核对。

源码方式运行界面：`python weibo_favorites_gui.py`（需先 `pip install customtkinter pillow requests`）。

以下为命令行版本说明（功能一致，适合脚本化/排错）。

## 功能

- 逐条下载收藏：正文（长微博自动取全文）、图片原图、用户名、发布时间、来源、原链接
- 转发微博：**只保存被转发的原博** —— 以原博身份建立顶层目录 `原博用户名-原博时间`（不带前缀），目录内是原博的正文、原博的图片；原博文本末尾附一行转发来源（转发者/转发时间/转发语）
- 断点续传：已存在的文件自动跳过，中断后重跑只补缺失项
- 进度清单：`downloads/已下载清单.json` 记录每条收藏状态（完成/部分失败/异常），`--list` 随时查看
- 每条收藏额外保存原始 JSON（`raw.json`），便于排查与断点识别

## 进度清单与下载控制

**查看哪些下载过**

```
python weibo_favorites_downloader.py --list
```

输出每条收藏的状态（`done` 完成 / `partial` 图片有失败 / `failed` 处理异常）、用户名、时间、图片数。清单文件为 `downloads/已下载清单.json`，`downloads/运行日志.log` 记录每次运行的开始与结果。

**开始 / 暂停 / 继续**

| 操作 | 命令 |
| --- | --- |
| 开始全量下载 | `python weibo_favorites_downloader.py` |
| 暂停 | 运行中按 `Ctrl+C`（进度自动保存，已下载文件不受影响） |
| 继续 | 重新运行同一条命令，自动跳过已完成的，只补未完成/失败的 |
| 只下载前 N 条 | `python weibo_favorites_downloader.py --limit 50` |
| 指定页范围 | `python weibo_favorites_downloader.py --start-page 5 --end-page 10` |
| 预览将要下载什么 | `python weibo_favorites_downloader.py --dry-run` |

说明：`partial`（图片有失败）的条目下次运行会自动重试补齐缺失图片；`failed` 的条目会自动重新处理。想强制重下某条，删除清单里对应条目（或删除该条目录）再运行即可。

## 使用步骤

1. 安装依赖

   ```
   pip install requests
   ```

2. 编辑 `config.json`，粘贴你的 Cookie：

   - 浏览器登录 `weibo.com`（建议收藏页）
   - 按 `F12` 打开开发者工具 → `网络(Network)` 面板
   - 刷新页面，找到 `weibo.com/ajax/collection` 开头的请求
   - 在 `请求头(Request Headers)` 中找到 `Cookie:` 一整段，完整复制到 `config.json` 的 `cookie` 字段

3. 先探测验证（强烈建议）：

   ```
   python weibo_favorites_downloader.py --probe
   ```

   成功后会生成 `probe_output.json` 并打印首条字段结构。若字段与脚本预期不符，把该文件发出来适配解析逻辑。

4. 全量下载：

   ```
   python weibo_favorites_downloader.py
   ```

## 输出目录结构

```
downloads/
├── 已下载清单.json          # 每条收藏的下载状态（--list 查看）
├── 运行日志.log             # 每次运行的开始/结束记录
├── 张三-2025-01-01 12-30-00/     # 普通微博（本人发布）
│   ├── 微博内容.txt              # 用户名/时间/来源/链接/正文
│   ├── raw.json                  # 该条微博原始 JSON
│   ├── 图片1.jpg
│   └── 图片2.jpg
└── 李四-2024-12-30 10-00-00/     # 转发微博 → 只保存原博（目录即原博身份，无前缀）
    ├── 微博内容.txt              # 原博正文 + 末尾附一行转发来源
    ├── raw.json                  # 原博原始 JSON
    └── 图片1.jpg
```

## 常用参数

| 参数 | 说明 |
| --- | --- |
| `--list` | 查看已下载清单（无需 Cookie），不下载 |
| `--probe` | 只拉第一页原始 JSON 到 `probe_output.json` 后退出 |
| `--dry-run` | 只预览将要保存的目录与图片数量，不写文件不下载 |
| `--start-page N` | 从第 N 页开始（配合断点续传） |
| `--end-page N` | 只下载到第 N 页 |
| `--limit N` | 本次最多处理 N 条（含跳过的已完成项） |
| `--config PATH` | 指定配置文件（默认 `config.json`） |

## 注意事项

- **Cookie 会过期**：请求返回 401/403 时说明需要重新复制 Cookie。
- **请控制频率**：脚本默认已随机延时（列表请求 1–3 秒、图片 0.3–1 秒），不要自行调得过小，避免触发风控/验证码。
- **接口可能改版**：微博接口变动频繁。若报"接口返回异常"或字段对不上，先跑 `--probe` 并反馈 `probe_output.json`。
- 视频/长文章不下载媒体本体，仅在文本中标注；图片为原图（统一走 `sinaimg.cn/large/`）。
- 仅用于个人内容备份，请遵守微博使用条款与相关法规。
